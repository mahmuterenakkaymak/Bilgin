4. **Answer card · both widths** — the table header and the chart title are the SQL alias as written, run through `measureName` (web/src/lib/chartFormat.js:38), which lowercases: `CountryName` becomes **"Countryname"**, and the card pairs it with `SEHIR_SAYISI` / `URUN_ID` (export-buttons-390.png, conversation-chart-refine-monthly-line-390.png, ask-golden-answer-chart-answer-with-chart-390.png).
