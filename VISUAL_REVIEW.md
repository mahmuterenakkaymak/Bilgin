## Real problems
1. **Board card · both widths** — the board is the only surface in the program that shows raw SQL column names. The number card's caption is `_column_label`'s fallback (`nl2sql/start/cards.py:61,159-168`: an alias that is not a schema column is returned as-is), so five of the demo's cards print "MUSTERI_KARTI", "NET_MIKTAR", "NET_CIRO", "BRUT_KAR", "GECIKEN_SATIR" under their headline number (landing-empty-state-1366.png, new-conversation-clean-start-1366.png, db-dot-user-ok-header-db-green-390.png) while the same value in a thread reads "Musteri karti" (card-answer-followup-card-answer-turn-1-1366.png). The card's mini table (`web/src/components/StartCard.jsx:27`) prints `{name}` raw too — "StockItemName" — and the cell CSS clips "QuantityOnHand" to "QuantityC" mid-word with no ellipsis (start-purchasing-start-purchasing-cards-1366.png). The first screen a user sees captions its own numbers like a query editor.
2. **Connections · admin** — the test button never gives up. `ConnectionsScreen.jsx:368` turns it into "Deneniyor…" and disables Kaydet for as long as the POST is in flight, and nothing on the path bounds the wait (`nl2sql/engine/guard.py`, `nl2sql/web/connections_api.py` hand pyodbc no login timeout), so an unreachable host holds the form open with no cancel and no sentence. That hang is why `admin-connections` timed out at both widths again and why the M25 feature nobody has ever seen is still unseen: db-dot-user-down-header-db-red-banner-1366.png shows the grey ring, not a red banner, and db-dot-user-down-ask-fails-fast-1366.png answers "KAYIT_SAYISI 0" instead of failing fast.
3. **Start board · 390 and 1366** — the same question can be pinned twice: `POST /api/start/cards` (`web/start_api.py:123` → `personal_from_audit`) never looks at what the person already pinned, so the board carries two identical cards (landing-empty-state-390.png) and the admin's KİŞİSEL list lists "Peki geçen ayla kıyasla?" twice (admin-ready-questions-ready-list-1366.png). A board that can duplicate itself reads as a rendering mistake.
4. **Sidebar · both widths** — every conversation row is titled with the thread's *first* question on one line, and the list has no height bound, so after a few threads the sidebar is a wall of "Eylül 2026'da en çok satan 5 ürün h…" rows distinguished only by "1 tur"/"2 tur" (conversation-chart-refine-monthly-line-1366.png, ask-golden-answer-chart-1366.png, conversation-three-turns-390.png), with GEÇMİŞ pushed a screen below.
