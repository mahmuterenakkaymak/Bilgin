# Visual review — M22 (landing, answer + chart, clarification, exports, saved/history, rules, users, map, dark mode, login/logout)

## Real problems
1. **Masthead chip + map list · 1366** — the product sells a competitor in its own header: the chip reads "Sentetik ERP (Netsis benzeri) · fake" on every desktop frame (landing-empty-state-1366.png, ask-golden-answer-chart-answer-with-chart-1366.png) and the map's dataset card repeats it (admin-map-onboard-map-blank-1366.png). Run 8 §2 says the display name becomes "Sentetik ERP" and the brand appears nowhere a person reads; a customer demo opens on this line.
2. **Every answer · both widths** — `serve` without `--dataset` silently opens the synthetic dataset (`_served_dataset()` → `config.DEFAULT_DATASET`), so the reviewed product answers in ERP codes: table headers `STOK_KODU / STOK_ADI / SATIS_MIKTARI`, `CARI_KOD / CARI_ISIM`, `AY / NET_CIRO`, and the evidence line says "3 adım · TBLSTHAR, TBLSTSABIT" (ask-golden-answer-chart-answer-with-chart-390.png, conversation-chart-refine-monthly-line-1366.png). The brief's own fallback is remembered → `wwi` → first indexed dataset, never the synthetic one; the whole demo surface is coded names because of one line.
3. **Masthead nav · 390** — the row masks only its right edge, and tapping a link scrolls it, so the previous destination survives as a fragment: the users frame starts at "Veritabanı haritası" (users-screen-users-table-390.png) and the map frame reads "ır  Kurallar  Veritabanı haritası" (admin-map-onboard-map-blank-390.png). After the most common action on a phone the app's only navigation looks like a typo, with no hint that "Sor" is one flick away.
4. **Nasıl hesapladım · both widths** — the panel that exists to justify the number drowns in it: `run_sql` and `submit_sql` print the model-facing row dump whole ("Kolonlar: STOK_KODU, STOK_ADI, SATIS_MIKTARI STK0013 | Kakaolu Bisküvi 500 g | 160 …") twice, ~600 characters of the table already above, and the fact chips print a second time under the SQL (ask-golden-answer-chart-evidence-open-390.png, conversation-three-turns-context-line-1366.png). At 390 the panel is a wall of text; the useful lines (SQL, tablolar, süre) are buried.
5. **History panel · 390** — "Kayıtlılar ve geçmiş" opens a panel capped near the full viewport directly under the toggle, so the composer drops below the fold and the only control that closes it is that same toggle, now off-screen above a 17-row list (saved-and-history-sidebar-sidebar-saved-history-390.png). Opening history on a phone is a one-way trip; the panel has no heading and no close of its own.

## Craft ideas
6. The landing screen never says which world it is asking about — the same two sentences for every dataset (EmptyState.jsx:9-10) while the chip that names it is truncated at 390. One line naming the dataset the question runs against makes the first screen feel connected to the data, and it is the line a demo points at.
7. "İndirildi" says a file left the browser, not what is in it: the user cannot tell whether the Excel holds the 18 rows on screen or the 50 the model was shown — the exact question an ERP user asks before pasting into a report. Naming the row count once ("18 satır indirildi") turns good feedback into trustworthy feedback.
