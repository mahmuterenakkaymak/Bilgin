# Visual review — M23 (conversations, start board and pinned cards, ready questions, rules, users, map, dark mode)

## Real problems
1. **Start board · both widths** — the board's only chart is unreadable: `.start-card-chart { height: 140px }` (web/src/styles.css:2647) leaves ~40 px of plot under the ECharts title, so the title lands on top of the y-axis numbers ("180" through "Satış miktarı") and the rotated category labels pile across the bars (start-sales-start-sales-cards-390.png, start-purchasing-start-purchasing-cards-1366.png, new-conversation-clean-start-1366.png, db-dot-user-ok-1366.png). A pinned chart is the card a user glances at; here it is a 30 px strip of overlapping text at every width.
2. **Conversation composer · both widths** — the box still holds the question you just sent: `send()` (web/src/App.jsx:181) never clears `text`, only `newConversation` does, so every follow-up starts by selecting and deleting a question the thread already shows as a bubble above, and at 390 the 2-row box shows a clipped copy of it instead of the "Sorunuzu yazın" hint (conversation-three-turns-turn-2-follow-up-390.png, conversation-chart-refine-bar-without-new-sql-1366.png). The one screen Run 7 added makes its own main action the most fiddly thing on the page.
3. **Pie chart · 390** — `_pie` (nl2sql/report/chart.py:192) sets no legend and no label rule, so ECharts truncates the outside labels to four characters: "Dom…", "Kaka…", "Toz Ş…", "Nohut 1 kg: 27…" (conversation-three-turns-turn-3-chart-only-390.png, conversation-three-turns-390.png). The same option at 1366 prints every name, so exactly on the phone the user cannot say which slice is which product — the only thing the chart adds over the table below it.
4. **Table cards · both widths** — `card_result` (nl2sql/start/cards.py:63) hands over every column while `.result-table` cells are `white-space: nowrap`, so the card's own measure falls off the right edge with no cue: "Teslim tarihi belirsiz sipariş satırları" shows CARI_KOD + CARI_ISIM and the count column is simply gone (start-purchasing-start-purchasing-cards-1366.png), and "Ürün grubu bazında ciro" cuts the header to "SATILA" and the totals to "257.959." (new-conversation-390.png, landing-empty-state-1366.png). A card that shows a question's answer without its number is worse than no card.
5. **The whole desktop pass · 1366** — the map flow's last click activates `synthetic_erp` (.hybrid/visual.json, admin-map-onboard), and both widths share one server, so from that page on every frame answers in ERP codes: chip "Sentetik ERP · fake", `STOK_KODU / Kakaolu Bisküvi 500 g`, "TBLSTHAR" (ask-golden-answer-chart-answer-with-chart-1366.png) — while the same page at 390 opens WideWorldImporters and "Juniper Scented Candle". Run 8 §2 makes `wwi` the review and demo face; the desktop half of this review, and of every review until this is fixed, is judging the world the brief bans.

The title on its own line is what turns the list from a decoration into a way back.
